Flores amarillas 

Una experiencia web visual, interactiva y romántica inspirada en la estética acuarela de **Studio Ghibli** (*El castillo vagabundo*, *Mi vecino Totoro*). 

Diseñada especialmente para regalar unas flores amarillas eternas llenas de luz, magia y detalles especiales.

---

## 🌟 Características

- 🎨 **Arte Estilo Studio Ghibli**: Paisaje de colinas verdes y cielo azul en pintura acuarela con un hermoso ramillete de girasoles.
- 🌾 **Efectos de Naturaleza y Viento**:
  - Semillas de diente de león flotando en la brisa.
  - Pétalos amarillos cayendo suavemente por la pantalla.
  - Líneas de viento deslizándose sobre el cielo.
- 💖 **Interacción al Tocar/Hacer Clic**: Al tocar la pantalla en cualquier lugar, brotan destellos luminosos (`✨`) y flores (`🌼`).
- 📱 **Diseño Responsive para Celulares**: Optimizado específicamente para lucir increíble en pantallas de smartphones y computadoras.
- ⚡ **Sin Librerías Externas**: Construido con HTML5, CSS3 y JavaScript Vanilla puro (Canvas API).

---

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica.
- **CSS3**: Variables CSS, efectos de cristal (*glassmorphism*), animaciones de viento y media queries para móviles.
- **JavaScript (ES6)**: Motor de partículas Canvas 2D y efecto Parallax 3D al mover el cursor o inclinar el dispositivo.
